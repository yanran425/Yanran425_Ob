# Ollama

## 2.1说明

- 开源的大模型管理平台，提供`client`和`webui`两种管理方式。
- 充分利用本地资源，既可以用CPU也可以使用GPU

## 2.2指令

```
ollama list
ollama run modelName [提示词] --verbose
ollama pull modelName
ollama show modelName

```
